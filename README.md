# SGV — Sistema de Gestão de Vendas · Boutique Brain

Ferramentas de venda do brechó.

- **Vitrine (clientes):** `index.html` — link público via GitHub Pages: https://boutique-brain.github.io/sgv-code/
- **Gerador de posts + catálogo (uso interno):** `gerador.html` — https://boutique-brain.github.io/sgv-code/gerador.html

## Como atualizar a vitrine
1. Abra o `gerador.html`, monte/edite as peças e salve no catálogo.
2. Clique em **Gerar vitrine**, gerando um `vitrine-brecho.html`.
3. Substitua o `index.html` do repositório por esse arquivo (renomeando para `index.html`) e faça commit/push.
